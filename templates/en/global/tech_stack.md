## 4. UI Protocol: ITP v3.0 (Tri-Artifact) [Optional - Only for projects with UI]
<!-- Core UI description protocol -->
> **Note:** If the project has no UI (e.g., CLI, Backend API, Library), this section can be deleted.

### 4.1 Tri-Artifact Strategy

| Artifact | Format | Reader | Responsibility |
|:---|:---|:---|:---|
| `screens/` | Multi-file HTML (`index.html` + `S-XX.html` + `_shared.css`) | Human (Browser) | **Global visual truth source** — Generated by `/archi.ui` Skill; each screen independently previewable |
| `ui_context.md` | Structured Markdown | AI (plan/code/audit/edit) | **AI screen index** — The only entry for AI to read UI structure; generated synchronously by same Skill; do not manually modify |
| `ui.md` | ITP v3.0 DSL | AI (code/audit) | Task-level UI scope declaration — Only declares screens/states this task is responsible for, do not redefine global layout |

- In code phase, use `ui.md` + `ui_context.md` + `design_tokens.json` as reference; `screens/S-XX.html` is **read-only visual reference**, implement equivalent effect using **project's own tech stack**

### 4.2 Naming (PrefixFunction)
Component naming must follow `prefix+function` format:
* **Btn**: Button | **Inp**: Input | **Txt**: Text/Label
* **Box**: Container | **Img**: Image/Icon | **List/Card/Modal**: As named.

### 4.3 Syntax Structure
* **Definition**: `Name [Layout] (Style/Content) -> #Interaction`
* **Layout Keywords**: `[Row]`, `[Col]`, `[Center]`, `[Between]`, `[Fill]`, `[Grid]`
* **Example**:
```
    BoxHeader [Row, Between]
      TxtTitle [H2] (Text: "Login")
      BtnClose [Ghost] (Icon: X) -> #CloseModal
```

### 4.4 Design Tokens
`design_tokens.json` defines project-specific visual language, generated by `/archi.start` from Brief:
- `primitivePalette`: Raw color scale (neutral gray + brand colors)
- `semanticTokens`: Semantic colors (Background/Primary/Text…) + font specs
- `layout`: Border radius/shadow/spacing sizes
- `motion`: Animation duration/easing/mode preference
- `illustration`: Illustration style/icon library
- **code phase**: All color/size/animation values must come from this file's corresponding fields, hardcoding magic values is forbidden

### 4.5 Delta Syntax
* **Usage**: For modifying existing UI snapshots.
* **Format**: `@Locator { + Add, ~ Modify, - Remove }`

* **No [Tech 1]:** [E.g., No Redux - too heavy for this project.]
