**UI Design Red Lines (Anti-patterns)**:
- **No purple gradient on white background** — AI default aesthetic signature
- **No Emoji as icons** (🔔📁⚙️) → Use self-drawn SVG or declared icon library
- **No all screens with same centered card layout** → List/Detail/Form must have obvious differences
- **No pure black + pure white** → Use layered grayscale palette
- **No generic feel** → Must immediately identify aesthetic direction when opened (Linear vs Notion vs Grafana)
- **No hardcoding** — Colors use Tokens, spacing use variables, no magic numbers
